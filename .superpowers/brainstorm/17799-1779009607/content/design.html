Design: Move and Merge Logic

Rotation-based approach for directional movement

1. Core Move Function (`moveLeft`)

For each row, we'll perform these steps:

  • Filter out empty cells to get a list of tiles.
  • Iterate through the list and merge adjacent tiles with the same value.
  • When merging: Create a new tile, set mergedFrom, and increment the score.
  • Fill the remaining spots in the row with empty cells (represented by the absence of a tile at that position).

2. Handling Other Directions

Instead of writing logic for Up, Down, and Right, we will:

  • Rotate the board so the target direction becomes "Left".
  • Apply moveLeft logic.
  • Rotate the board back to its original orientation.
Rotation Mapping

Move Right: Rotate 180° -> Move Left -> Rotate 180°

Move Up: Rotate 270° -> Move Left -> Rotate 90°

Move Down: Rotate 90° -> Move Left -> Rotate 270°

3. Game State Updates

  • Won: If any tile reaches 2048.
  • Over: If no empty cells remain AND no adjacent tiles can be merged.
  • New Tile: A new random tile (2 or 4) is added after every successful move.
