# 2048 遊戲設計規範

**日期：** 2026-05-17
**狀態：** 已批准
**技術棧：** React, TypeScript, Vite, Vanilla CSS

## 1. 概述
一個高效能、視覺忠於原著的 2048 益智遊戲。該應用程式將支援多種棋盤大小、持久化最高分紀錄，並針對桌面和行動裝置優化流暢的動畫效果。

## 2. 技術棧
- **框架：** React 18+ (TypeScript)
- **建構工具：** Vite
- **樣式：** CSS Modules 或 Vanilla CSS，用於效能關鍵的動畫。
- **狀態管理：** 使用 `useReducer` 的自定義 Hook 來處理複雜的遊戲邏輯。
- **持久化：** `localStorage` 用於存儲最高分，以及可能的當前遊戲狀態。

## 3. 核心功能
- **棋盤系統：** 動態生成棋盤，支援 3x3, 4x4, 和 5x5。
- **遊戲邏輯：**
  - 隨機生成 '2' 或 '4' 數字塊。
  - 方向性合併邏輯（上、下、左、右）。
  - 勝利條件（達到 2048 數字塊）和遊戲結束條件（無可用移動）。
- **計分：**
  - 當前分數（合併數字塊的總和）。
  - 最高分（跨會話持久化）。
- **輸入方式：**
  - 鍵盤：方向鍵和 WASD。
  - 行動裝置：觸控滑動手勢（使用 `touchstart` 和 `touchend`）。
- **動畫：**
  - CSS Transitions 用於數字塊移動（位置變化）。
  - CSS Keyframes 用於數字塊出現和合併時的縮放效果。

## 4. UI/UX 設計
- **主題：** 經典 2048（米色/棕色色調）。
- **響應式佈局：** 居中的遊戲棋盤，可在較小屏幕上適當縮放。
- **控制：** 「新遊戲」按鈕和棋盤大小選擇器。

## 5. 實施策略
- **數字塊唯一性 (Tile Identity)：** 每個數字塊將具有唯一的持久 ID，以確保 React 可以在移動過程中追蹤它，從而實現 CSS 過渡動畫。
- **棋盤表示：** 使用扁平數組或嵌套數組，其中每個元素是一個 `Tile` 對象或 `null`。
- **移動演算法：**
  1. 過濾非空數字塊。
  2. 合併相鄰的相同數字塊。
  3. 移至目標方向。
  4. 與先前狀態進行比較，以確定移動是否有效。

## 6. 測試計劃
- **單元測試：** 合併數字塊和檢查遊戲結束條件的邏輯。
- **整合測試：** 驗證分數更新和 `localStorage` 持久化。
- **手動測試：** 驗證滑動靈敏度和鍵盤響應速度。
